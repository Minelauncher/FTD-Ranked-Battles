- 제출할 때는 제출자 게임에서 BP 비용을 계산한다. 전투 시 BP 해시·금지 블록·배치 제한·제출 예산의 일관성 검사는 유지한다.

- 목록 위아래의 페이지 버튼을 제공하고 페이지를 바꾸면 맨 위로 이동한다. 새로고침은 현재 페이지를 유지한다.

- 순위·동점·색상 백분위는 대회 전체 기준을 유지한다. 한국어·일본어·영어 지원.

대회 선택 → 함대·진형 편집 → 제출 → 상대 찾기 → 전투 시작.
대회마다 제출 함대·레이팅·경기 수·순위·전적이 독립적이다. 새 대회는 1,000점부터 시작한다.
해당 대회의 인간·기본 상대 중 점수가 가장 가까운 최대 5개에서 무작위 매칭한다.
대회·전적은 배경이 분리된 항목으로 표시하며 제목·점수·승패를 크게 보여 준다.
레이팅 숫자와 랭킹 보드 글씨는 해당 대회 인간 참가자 전체 순위의 백분위로 색을 나눈다.
0~24 회색, 25~49 초록, 50~74 파랑, 75~94 보라, 95~98 주황, 99~99.99 분홍, 100 금색.
색상 백분위 = 100 × (참가자 수 - 순위) / (참가자 수 - 1). 동점자는 같은 순위·색이다.
아직 경기가 없거나 한 명뿐이면 기본색. 기본 상대는 기존대로 순위표·색상 모집단에서 제외한다.
색상은 레이팅 계산·매칭 규칙에 영향을 주지 않는다.
일반 유저와 기본 상대 모두 양쪽 점수를 반영한다. 다른 대회에는 영향이 없다.
상대가 실행한 경기에서도 내 점수·경기 수·전적이 바뀐다. 전적에서 실행한 쪽을 구분한다.
계정당 진행 중 경기는 전체 대회에서 한 개다. 다른 매칭 전에 완료하거나 항복한다.

서버: https://ftd-ranked.ftd-ranked.workers.dev
관리자: https://ftd-ranked.ftd-ranked.workers.dev/admin
Workers Free + D1 Free + SQLite Durable Objects Free를 사용한다. BP는 D1에 압축 저장하며 R2 구독은 사용하지 않는다.
현재 제출 함대·진행 경기에서 쓰지 않는 BP 원본은 24시간 유예 후 자동 정리한다. 전적·레이팅은 유지한다.
BP 저장 DB 추가·이전 및 자동 정리 절차: server/cloudflare/STORAGE.txt. 현재는 기존 DB 하나를 사용한다.
실제 전투는 사용자의 FTD에서 실행한다. 모드 검사나 공식/비공식 구분은 없다.
관리자는 대회와 기본 상대의 BP·수량·진형·점수, 규칙과 최소 모드 버전을 편집한다.
관리자 웹 화면에서 DB 사용량·남은 용량, 최근 BP 정리 내역, BP 검색·원본 다운로드도 제공한다.
새 전투 방식의 실행 코드가 필요한 경우에는 모드 업데이트가 필요하다.

운영 대회 (2026-10-24): 기체 소환비 합계 + 남는 보급 자원 = 팀 예산.
- 100k Materials - Ocean: 100,000 / BP 종류 10 / 배치 10 / Neter E11.5 N6.5.
- 500k Materials - Ocean: 500,000 / BP 종류 5 / 배치 5 / 동일 Neter 좌표.
- 250k Materials - Land: 250,000 / BP 종류 5 / 배치 5 / AOTE E1.5 N1.5.
- 이름은 예산과 전장 환경을 뜻한다. 기체 종류 제한은 없으며 각 대회의 예산·배치 등 규칙을 따른다.
대회 이름·설명·기본 상대 이름은 영어 원문으로 제공하며 UI 언어 선택과 무관하다.
새 함대전·지상전 기본 상대는 각 3개, 임시 시작 점수 900/1100/1300.
전장·규칙·BP·수량·진형·레이팅은 관리자 서버 화면에서 변경한다.
세 대회의 교전거리는 1,000m이며 BP 종류·배치 제한은 위 대회별 값을 따른다.
배치 깊이는 팀당 1,000m. 좌우·고도가 같다면 앞/앞 1,000m, 뒤/뒤 3,000m다.
묶음 BP는 배치 1개로 세며 비용은 포함된 기체 전부를 합산한다.
항공전 기본 상대는 Duster 4대, Falcon 3대, Flying Squirrel 편대이며 승패에 따라 점수가 변한다.
전투는 1배속, 기본 제한 10분. 전멸 우선, 시간 종료 시 남은 기체 비용과 보급 자원 합계가 높은 쪽이 판정승.
소수 셋째 자리까지 비교하여 같으면 무승부. 보조기도 포함한다. 이전에 발급된 경기는 기존 체력비 판정을 유지한다.

함대 이름은 1~40자. 기체별 수량, 드래그 배치도, 단일/동일 BP 전체 교체를 지원한다.
X의 +는 오른쪽, Z=0은 선두, 음수 Z는 뒤쪽. 방향 0도는 적을 향한다.
드래그: 기본 1m, Shift 10m, Alt 자유 배치. 고도·방향은 별도 수치로 편집한다.
BP 교체와 드래그는 기존 고도·방향을 유지한다. 배치 고도는 해수면 기준이다.
보통 기체가 지형에 묻히면 게임이 위로 보정하지만 공중의 기체를 땅으로 내려주지는 않는다.
BP 안의 AI 고도 설정과 시작 배치 고도는 별개다.
편집안은 Drafts, 내가 선택한 BP 원본은 FleetBlueprints에 저장한다. 제출해야 서버에 반영된다.
로그인하면 서버 제출본과 이 PC의 편집안을 불러온다. 매칭에는 제출본을 사용한다.

BP 내용·기체별 수량 변경에만 대회별 교체 제한을 적용한다. 현재 세 대회는 1분이다.
함대 이름·위치·고도·방향 변경은 대기 없이 제출 가능하며 BP 교체 시각을 바꾸지 않는다.
진행 중인 내 경기가 있으면 제출을 막는다. 발급된 BP·진형·규칙·점수는 고정된다.
금지 블록은 실제 BP의 본체·포탑·보조기 구조를 매 제출마다 검사한다.
같은 이름의 BP라도 내용이 달라지면 별도 BP로 취급한다.
내 제출 진형과 BP 다운로드 진행량을 전투 탭에서 확인한다.
경기 후 다운로드 BP·임시 전투 파일만 삭제한다. 내 BP·편집안·전적은 유지한다.

랭크 관전 중 ESC는 전용 메뉴를 연다. 커스텀 배틀 Setup·재시작·진형 변경은 차단한다.

기능별 사용 안 함·모든 기본값 복원을 지원하고 client.json에 즉시 저장한다.
모드 내부 중복 키는 적용하지 않는다. 기본 게임·다른 모드와의 충돌은 직접 피해야 한다.
메뉴나 입력창을 열었을 때는 관전 단축키가 실행되지 않는다.
메뉴에서 전체 보기와 개별 기체 추적을 선택한다. 양쪽 편대 모두 추적할 수 있다.
FTD 기본 자유/기체 카메라와 카메라 HUD를 사용한다. 궤도·줌·기체 기준 이동,
기체의 회전축 고정/해제·카메라 위치 편집은 기본 카메라 UI와 게임 입력 설정을 따른다.
카메라 타깃 선택으로 AI 우선 공격 대상을 지정하지 않으며 수동 조종·사격은 막는다.
전장 준비 중부터 기체 배치를 기준으로 수면·지형 위 시점을 잡는다.
메뉴를 열어도 진행 중 전투는 멈추지 않는다. 일반 커스텀 배틀에는 이 제한이 없다.

- 설치 ZIP의 RankedBattles 폴더를 FTD가 사용하는 Mods 폴더 안에 놓는다.
  plugin.json, header.header, header.jpg, RankedBattles.dll, 0Harmony.dll, README.txt 여섯 배포 파일을
  그대로 유지한다. Linux의 대소문자 구분에 맞춰 파일 이름을 바꾸지 않는다.
- 로그인 설정/보류 결과/함대 편집안/BP는 기존처럼 쓰기 가능한 모드 폴더에 저장한다.
  쓰기 불가능하거나 어셈블리 경로가 없는 경우 FTD 저장 루트의 RankedBattles 폴더를 쓴다.
  이 위치는 FTD의 SaveLocation 설정을 따른다. OS 사용자 폴더를 직접 추측하지 않는다.
- 대체 저장 위치를 사용하면 기존 client.json, pending-result.json, Drafts, FleetBlueprints를
  원본 바이트 그대로 한 번 복사하고 이후 같은 위치를 계속 사용한다. 원본은 보존한다.
  .storage-ready 파일은 완료 표시다. 이미 접수된 결과를 다시 가져오지 않도록 삭제하지 않는다.
- JSON과 BP는 UTF-8로 임시 파일에 완전히 쓴 뒤 교체한다. File.Replace 미지원 런타임에서는
  이름 변경/백업 복원으로 이전 파일을 보호한다. 보류 결과 삭제 시 복구 백업도 함께 지운다.
  손상된 설정/보류 결과는 덮어쓰지 않으며, 로컬 저장소 오류 상태에서는 서버 작업을 막는다.
  오류를 해결한 뒤 게임을 재시작한다. 모드 메뉴 자체는 계속 사용할 수 있다.
- 빌드: PowerShell 7에서 ./Build.ps1 -GameManaged '<FTD의 Managed 폴더>'
  Harmony DLL을 별도로 갖고 있다면 -HarmonyPath '<0Harmony.dll 경로>'를 지정한다.
  .NET SDK와 해당 플랫폼 FTD의 Managed DLL이 필요하다. 일반 사용자는 ZIP만 설치하면 된다.
  테스트를 포함하려면 -Tests (.NET 10 SDK). 저장 단위 검사는 Unity 없이 실행된다.

  동봉 Harmony 2.4.2는 공식 문서상 Windows/Unix/macOS Mono 지원 계열이다.

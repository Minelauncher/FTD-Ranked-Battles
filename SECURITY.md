# Security review and reports

This project has not completed an independent security audit. AI assistance and automated regression tests are disclosed in the README; neither establishes a safety guarantee.

For ordinary defects, open an Issue with the affected commit, file/line, expected behavior and a minimal reproducer using synthetic data. Do not test attacks against the live community service, access another player's account, or upload real credentials or database contents.

For a suspected vulnerability that could expose accounts or private data, first contact the maintainer through the Workshop profile to arrange a private report. Do not paste an exploit, live token, password, recovery code or private email into public comments/Issues. GitHub private vulnerability reporting is not assumed to be enabled.

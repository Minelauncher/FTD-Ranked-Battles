# Third-party components and data

- From the Depths and its managed assemblies, campaign designs and terrain belong to their respective owners. Obtain game dependencies from your own installation. Game DLLs, decompiled game code and campaign/user blueprints are not distributed by this source repository.
- The terrain overview PNGs and generated `battlefield-maps.js` describe sampled Neter/Ashes of the Empire terrain. `block-catalog.js` contains game block names and identifiers. These are game-derived data used for interoperability; no independent ownership or blanket license for them is claimed.
- Harmony 2.4.2 is an external runtime dependency by Andreas Pardeike and contributors: https://github.com/pardeike/Harmony . Obtain its binary and license from upstream. `0Harmony.dll` is not included in this repository.
- Newtonsoft.Json and Unity modules are referenced from the installed game rather than copied into this repository.
- Cloudflare Wrangler, Miniflare and their transitive dependencies are listed in the server's pinned package lockfile. Their upstream licenses apply.
- The Workshop header is AI-assisted promotional artwork; the source repository includes the same header file for packaging transparency.

A project-wide open-source license for the author's code has not yet been selected. Public visibility should not be described as an MIT/Apache license or as an independent endorsement.
